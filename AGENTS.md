# Eyedence website

Work in this repository, independently of `/git/alef/revops`.

- Stack: React, TypeScript, Vite; static output in `dist/`.
- Write product copy and documentation in British English.
- Keep CSS tokens in `src/styles.css`. Preserve responsive layouts and visible keyboard focus.
- Label fictional product examples. Do not invent customers, commercial results, contact details or compliance promises.
- Avoid external services, trackers and backend requirements unless requested.
- Run `npm run build` and relevant Playwright checks after changes.
- Keep secrets, dependencies, generated output and browser artifacts out of Git.
- Publication is separate from implementation. Do not change hosting plans or publish without authorisation.
